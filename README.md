# Kingdom Battle

브라우저에서 실행하는 가벼운 디펜스 게임입니다. 고블린, 오크, 오크왕이 웨이브로 밀려오며, 하늘매 궁수탑·라이언하트 병영·아케인 스파이어·블래스트포지 포탄탑으로 왕국을 지켜냅니다.

## 실행 방법
1. 저장소 루트에서 `index.html`을 브라우저로 열어 주세요.
2. "게임 시작" 버튼을 눌러 웨이브를 시작하고, 원하는 타워 버튼을 고른 뒤 슬롯을 클릭해 배치하거나 업그레이드합니다.
3. BGM/효과음 버튼으로 간단한 배경음악과 전투 효과음을 켜거나 끌 수 있습니다.

## 특징
- 각 적의 HP 바 표시
- 타워 업그레이드 및 특화 능력(슬로우, 관통, 광역 피해)
- 간단한 배경음악 루프와 효과음 생성
